# 🏰 매쓰 카드 디펜스 (Math Card Defence)

빠른 두뇌 회전과 카드 전략이 결합된 웹 기반 수학 연산 실시간 타워 디펜스 게임입니다!

---

## 🎮 게임 소개
몬스터들이 성벽을 향해 몰려옵니다! 
아래에 주어지는 연산 카드를 조합하고 계산식을 풀어 강력한 마법과 유닛을 소환해 성벽을 방어하세요.

- **장르**: 수학 퍼즐 + 실시간 타워 디펜스
- **플랫폼**: PC 및 모바일(스마트폰/태블릿) 완벽 반응형 지원
- **구현 기술**: Pure HTML5, CSS3, Vanilla JavaScript (외부 라이브러리 및 에셋 의존성 제로)
- **사운드**: Web Audio API 기반의 자체 신디사이저 사운드 엔진 내장

---

## 🕹️ 플레이 방법
1. **난이도 선택**: 초보(기초 연산)부터 지옥 난이도까지 선택할 수 있습니다.
2. **카드 선택 & 수식 완성**: 하단 덱에서 카드를 터치/클릭하여 문제의 정답을 완성합니다.
3. **유닛 소환 & 마법 시전**:
   - 올바른 정답을 제출하면 강력한 방어 유닛이 소환되거나 광역 마법이 발동합니다.
   - 콤보(Combo)를 쌓으면 **FEVER TIME**이 발동하여 더 빠른 공격과 강력한 보너스를 획득합니다.
4. **성벽 방어**: 몬스터가 성벽에 닿지 않도록 최대한 오래 생존하여 높은 티어와 점수를 달성하세요!

---

## 🚀 로컬 실행 방법
별도의 빌드 과정 없이 정적 웹 서버나 브라우저에서 바로 실행할 수 있습니다.

### 방법 1: Node.js 내장 로컬 서버
```bash
node server.js
```
브라우저에서 `http://localhost:8080` 접속

### 방법 2: 브라우저 직접 열기
`index.html` 파일을 더블 클릭하여 바로 플레이할 수 있습니다.
